## 💡 Γιατί φτιάχτηκε

Έψαχνα ένα εργαλείο που να του λες μια διεύθυνση και να σου απαντάει αν βρίσκεται **μέσα ή έξω από τον Δακτύλιο**. Δεν υπάρχει.

Ό,τι κυκλοφορεί είναι στατικές εικόνες, ή το πολύγωνο του Δακτυλίου σαν **overlay πάνω στο Google Maps** (KML/My Maps) — που απλώς το **βλέπεις**. Δεν μπορείς να ψάξεις μέσα του, δεν μπορείς να γράψεις μια οδό και να πάρεις απάντηση, δεν μπορείς να περιηγηθείς σε επίπεδο δρόμου και να ελέγξεις συγκεκριμένη διεύθυνση.

Οπότε το έφτιαξα, για να το χρησιμοποιεί όποιος θέλει. 🎯

| 📏 **Απόσταση από το όριο** | Σου δείχνει πόσα μέτρα απέχεις από τη γραμμή του Δακτυλίου — χρήσιμο για **«πόσο κοντά είμαι στο να βγω έξω»** |
| 🚶 **Για όποιον θέλει να περπατήσει** | Αν αφήνεις το αυτοκίνητο έξω και περπατάς προς τον προορισμό, βλέπεις πόσο κοντά είσαι στο όριο |
| 🅿️ **Parking εκτός Δακτυλίου** | Βρίσκει parking **έξω** από τον Δακτύλιο, ταξινομημένα κατά απόσταση από το σημείο σου |

| ⭕ **Έλεγχος ορίου** | Ξεχωρίζει αν είσαι **πάνω στη γραμμή** του ορίου (όπου τα μέτρα δεν ισχύουν) από το μέσα/έξω |
| 📱 **Παίζει σε κινητό** | Πλήρως responsive — iPhone, iPad, Android — με bottom sheet και safe areas για iOS |

## 🔧 Πώς λειτουργεί κάτω από το καπό

- **Όλα τα γεωμετρικά γίνονται τοπικά** στον browser: ο έλεγχος μέσα/έξω (ray casting) και η απόσταση από το όριο (κλειστού τύπου προβολή + haversine) υπολογίζονται με **ακρίβεια χιλιοστού**, χωρίς επιπλέον κλήσεις στο Google API.
- **Το όριο** φορτώνεται από το `data/daktylios.geojson` — 546 σημεία, επαληθευμένο ενάντια στα επίσημα δεδομένα του Δήμου Αθηναίων.
- **Advanced Markers** (το τρέχον Google API, χωρίς deprecation warnings) όταν υπάρχει Map ID — αλλιώς πέφτει αυτόματα σε κλασικά markers.
- **Browser caching** για το parking, ώστε να μη σπαταλιούνται κλήσεις.

## 🧰 Τι χρειάζεσαι για να το στήσεις

### 1️⃣ Web hosting με **PHP 7.4+**
Οποιοδήποτε κοινό hosting (cPanel, shared, VPS) με PHP. Δεν χρειάζεται database, framework ή Composer. Χρειάζεται μόνο η επέκταση **cURL** (υπάρχει σχεδόν παντού).

### 2️⃣ Λογαριασμός **Google Cloud** με ενεργοποιημένα **3 APIs**
Στο [Google Cloud Console](https://console.cloud.google.com/):

| API | Για τι χρησιμεύει |
|:---|:---|
| 🗺️ **Maps JavaScript API** | Ο ίδιος ο χάρτης + advanced markers |
| 📮 **Geocoding API** | Μετατροπή συντεταγμένων ↔ διεύθυνσης (click στον χάρτη) |
| 🏢 **Places API (New)** | Autocomplete διευθύνσεων + αναζήτηση parking |

### 3️⃣ Ένα **API Key** (και προαιρετικά ένα **Map ID**)
- Το **API Key** το φτιάχνεις στο Cloud Console → *Keys & Credentials*.
- Το **Map ID** (προαιρετικό, για τα advanced markers) στο *Map Management* → τύπος **JavaScript / Vector**.

> ⚠️ **Χρειάζεται πιστωτική κάρτα** στον λογαριασμό Google Cloud για να ενεργοποιηθούν τα APIs — αλλά για προσωπική χρήση δύσκολα θα χρεωθείς. Δες παρακάτω το [κεφάλαιο για τη χρέωση](#-κόστος--χρέωση-google).

## 🚀 Οδηγός εγκατάστασης βήμα-βήμα

### Βήμα 1 — Κατέβασε τον κώδικα
```bash
git clone https://github.com/greatvc/daktylios-athina.git
cd daktylios-athina
```

### Βήμα 2 — Φτιάξε το `config.php`
Αντίγραψε το παράδειγμα και συμπλήρωσε τα δικά σου κλειδιά:
```bash
cp config.example.php config.php
```
Άνοιξε το `config.php`:
```php
<?php
return [
    'google_maps_api_key' => 'ΤΟ_API_KEY_ΣΟΥ',
    'google_maps_map_id'  => 'ΤΟ_MAP_ID_ΣΟΥ',   // προαιρετικό — άφησέ το κενό αν δεν έχεις
];
```

### Βήμα 3 — Κλείδωσε το API Key σου 🔒
Αυτό είναι **σημαντικό**. Στο Cloud Console, στο API Key:
- **Application restrictions** → *HTTP referrers* → πρόσθεσε το domain σου (π.χ. `https://tosite.gr/*`)
- **API restrictions** → επίλεξε μόνο τα 3 APIs παραπάνω
- Βάλε **budget alert** για να σε ειδοποιεί αν πλησιάσεις κάποιο όριο

> Το Maps JavaScript key είναι **αναγκαστικά ορατό** στον κώδικα της σελίδας — δεν κρύβεται. Η πραγματική προστασία σου είναι οι **referrer restrictions**, όχι η απόκρυψη.

### Βήμα 4 — Ανέβασέ το στο hosting
Ανέβασε όλα τα αρχεία στον φάκελο που θες (π.χ. `public_html/daktylios/`). **Κράτα το `config.php` εκτός Git** (δες `.gitignore`).

### Βήμα 5 — Προστάτεψε το `config.php` (προαιρετικό αλλά συνιστάται)
Φτιάξε ένα `.htaccess` μέσα στον φάκελο για να μπλοκάρει την άμεση πρόσβαση:
```apache
<FilesMatch "(?i)^config.*\.php.*">
    Require all denied
</FilesMatch>
Options -Indexes
```

### Βήμα 6 — Άνοιξε το site 🎉
Πήγαινε στο `https://tosite.gr/daktylios/` και δοκίμασε 2-3 διευθύνσεις που ξέρεις σίγουρα ότι είναι μέσα και έξω.

## 💰 Κόστος & χρέωση Google

**Σύντομη απάντηση:** για προσωπική χρήση, σχεδόν σίγουρα **δεν θα πληρώσεις τίποτα** — αλλά πρέπει να έχεις κάρτα στον λογαριασμό.

Από **1 Μαρτίου 2025** η Google **κατάργησε** το παλιό ενιαίο πιστωτικό των $200/μήνα και το αντικατέστησε με **δωρεάν όριο ανά API (SKU)**:

| Κατηγορία | Δωρεάν κλήσεις / μήνα (ανά API) |
|:---|:---|
| **Essentials** (Maps JS, Geocoding) | ~10.000 |
| **Pro** (Places – autocomplete, nearby) | ~5.000 |

Για ένα προσωπικό εργαλείο με λίγες δεκάδες ή εκατοντάδες αναζητήσεις τον μήνα, **μένεις άνετα μέσα στα δωρεάν όρια**. Η χρέωση ξεκινά μόνο αν το site σου δέχεται χιλιάδες επισκέψεις.

> 📌 **Προστασία από εκπλήξεις:** βάλε **budget alerts** και **quotas** ανά API στο Cloud Console. Έτσι, ακόμα κι αν κάτι πάει στραβά, ειδοποιείσαι πριν χρεωθείς.

- [Google Maps Platform — Pricing](https://mapsplatform.google.com/pricing/)

## 🔄 Ενημέρωση κάθε σεζόν

Οι κανόνες του Δακτυλίου (περίοδος εφαρμογής, ωράρια, αργίες) αλλάζουν κάθε σεζόν με ΚΥΑ. Αν προσθέσεις έλεγχο μονών/ζυγών, οι σχετικές σταθερές μπαίνουν στην αρχή του `js/app.js`. Το ίδιο το **όριο** του Δακτυλίου δεν αλλάζει.

## ⚠️ Σημαντικές διευκρινίσεις

- Στις **οριακές οδούς** του Δακτυλίου (Αλεξάνδρας, Πατησίων, Πειραιώς, Συγγρού, Ιερά Οδός κ.λπ.) τα μέτρα περιορισμού **δεν ισχύουν**. Γι' αυτό η εφαρμογή ξεχωρίζει το «ΠΑΝΩ ΣΤΟ ΟΡΙΟ».
- Οι αποστάσεις είναι **σε ευθεία γραμμή**, όχι περπάτημα. Το πραγματικό περπάτημα ακολουθεί δρόμους και είναι μεγαλύτερο.
- Ο αριθμός parking είναι **καταχωρημένα σημεία** της Google, όχι ελεύθερες θέσεις σε πραγματικό χρόνο.
- **Δεν είναι επίσημη υπηρεσία.** Για πρόστιμα, εξαιρέσεις και ειδικά σήματα ισχύει η εκάστοτε ΚΥΑ και το gov.gr.
